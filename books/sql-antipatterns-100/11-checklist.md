---
title: "巻末チェックリスト"
free: false
---

- SELECT で必要なカラムを明示している（SELECT * を使っていない）
- 絞り込み・集計をアプリ側ではなく DB 側で行っている
- 一覧取得に LIMIT / ページングの上限がある
- ORDER BY のない「先頭1件」に依存していない
- ループ内のクエリ発行（N+1）がない
- WHERE でカラムに関数や演算を適用していない
- 日付範囲は「開始以上・終了未満」で書いている
- NULL 判定は IS NULL、否定の存在条件は NOT EXISTS で書いている
- 結合条件は JOIN ... ON で明示し、粒度（行の重複）を確認した
- LEFT JOIN の条件を WHERE に書いて潰していない
- 集計前に JOIN による行の膨張がないか確認した
- 順位・累計・前行比較にウィンドウ関数を使っている
- 検索パターンに合う複合インデックスがあり、列順が正しい
- 一意性は UNIQUE 制約で保証している（アプリの事前チェックだけに頼らない）
- 更新・削除の前に同条件の SELECT で対象を確認した
- 大量更新・削除はチャンク分割し、トランザクションを短く保っている
- 不可分な更新は1つのトランザクションにまとめている
- カウンタや在庫は原子的な条件付き更新で変更している
- ロック取得順序がアプリ全体で統一され、デッドロック時のリトライがある
- 金額は DECIMAL、日時は日時型、識別子は文字列で保存している
- NULL の扱い（統一表現・COALESCE・NOT NULL 既定）を決めている
- 保存時のタイムゾーンは UTC に統一している
